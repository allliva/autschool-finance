# АутШкола — Кабинет авторов

Учебное веб-приложение для учёта продаж, авторских начислений и выплат.

## Возможности

- административный кабинет с продажами, товарами, авторами, выплатами и статистикой;
- личный кабинет автора с начислениями, прогрессом до выплаты и историей выплат;
- отдельный read-only демо-вход в наполненный кабинет Марины;
- Firebase Authentication и Firestore в качестве backend;
- публикация frontend через GitHub Pages;
- резервная версия на Firebase Hosting.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Сборка

Обычная сборка для корня сайта:

```bash
npm run build
```

Сборка для GitHub Pages выполняется workflow командой:

```bash
npm run build -- --base=/autschool-finance/
```

## Безопасность демо

Кнопка демо создаёт анонимную Firebase-сессию без встроенных в frontend логина и пароля. Firestore Security Rules разрешают такой сессии читать только тестовые `earnings` и `payouts` Марины. Создание и изменение любых финансовых документов запрещено серверными правилами.
